# StreamSafe 4D
Real-time Industrial Safety Streaming Platform is a streaming safety “digital twin” for factories and warehouses. Cameras send video to lightweight edge services that detect workers, forklifts and panel areas using object detection. Short video clips are classified into 8 workplace behavior classes (safe and unsafe). These behavior events, along with machine telemetry, flow through Confluent as real-time streams. Vertex AI refines risk scores per worker and zone, while Gemini turns incident streams into human-readable safety explanations and shift summaries. A React dashboard shows a live map of the facility with risk levels and incidents, demonstrating how real-time data in motion makes safety proactive instead of reactive.
